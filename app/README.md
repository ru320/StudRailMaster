# Stud Rail Master (Python package)

Drive toy trains with BLE motor hubs (JMC, Mould King 4.0) from your PC – offline, no account, no cloud.

```bash
pipx install "stud-rail-master[window]"
stud-rail-master            # or: stud-rail-master --demo
```

Full documentation (English and German) lives in the project repository:
`README.md`, `README.de.md`, `docs/en/`, `docs/de/` (developers: `docs/en/dev/`, `docs/de/entwickler/`).
